# Bundled fonts

66 Google Fonts are bundled locally for titles and captions. No external font requests are required. Latin characters are included; other scripts use the device fallback.

Roboto, Open Sans, Lato, Montserrat, Poppins, Nunito, Merriweather, Playfair Display, Source Sans 3, Roboto Mono, Oswald, Raleway, Inter, Ubuntu, Noto Sans, Noto Serif, PT Sans, PT Serif, Roboto Slab, Rubik, Work Sans, Fira Sans, Quicksand, Barlow, Mulish, Manrope, DM Sans, DM Serif Display, Libre Baskerville, Libre Franklin, Crimson Text, Cormorant Garamond, EB Garamond, Lora, Bitter, Arvo, Josefin Sans, Josefin Slab, Cabin, Karla, Inconsolata, Source Code Pro, Fira Code, IBM Plex Sans, IBM Plex Serif, IBM Plex Mono, Space Grotesk, Space Mono, Righteous, Anton, Bebas Neue, Pacifico, Dancing Script, Great Vibes, Lobster, Satisfy, Caveat, Comfortaa, Exo 2, Titillium Web, Assistant, Hind, Oxygen, Varela Round, Archivo, Dosis.

Where a family does not publish a bold or italic face, the browser synthesises that style from its available face in both preview and export.
