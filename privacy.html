Privacy

Ordo is a free video editor for Android and Windows. Your media is edited and rendered on your device.

Last updated: 25 October 2026

Media and project files

Ordo accesses video, images, audio, captions and project files that you choose to import. Editing, audio processing and video rendering take place locally. Ordo does not upload your media or projects to a developer-operated server.

Data stored on your device

The app stores settings, project recovery snapshots and remembered media locally. Remembered media may include cached files or saved file-access references so projects can reconnect to their source files. Rendering may create temporary files in the app's cache. Exported videos and project files are saved to the location you choose.

Accounts, advertising and tracking

Ordo does not require an account and does not include advertising, third-party analytics or advertising trackers. Fonts are bundled with the app for offline use. The developer does not sell your media or project data.

Internet connections and updates

On Android, Ordo checks a public release manifest hosted on GitHub for available updates. This request includes the installed app version code and a timestamp; it does not include your media or project contents. GitHub and its delivery providers also receive ordinary connection information, such as your IP address and request headers. Downloading an update opens a GitHub-hosted APK link in an external app.

This website and downloads

The Ordo website is hosted on GitHub Pages, and installers are hosted on GitHub Releases. The website does not add analytics scripts, advertising trackers or cookies of its own. GitHub may process technical information for hosting, security and downloads under its privacy statement. External links are subject to the destination's privacy practices.

Permissions and your choices

File access is used to open and save the files you select. Android notifications are used for native background-export progress and completion. You can manage permissions in your device settings. Where available, you can disable remembered media in Ordo. Clearing app data or uninstalling removes app-managed local data subject to your operating system's backup and restore behaviour; files exported or saved outside app storage must be deleted separately.

Support and information you share

If you submit a GitHub issue, information you choose to include is handled by GitHub and may be public. Do not include private footage, personal details or confidential project files in a public issue. For privacy questions, contact the maintainer through the Ordo GitHub issue tracker.

Changes to this statement

This page will be updated when Ordo's privacy practices change. The date above identifies the latest revision.
