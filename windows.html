A desktop editor that feels like one.

Media on the left, the picture in the middle, settings on the right and every track below. Menus, shortcuts and the mouse work the way you expect.

Download for Windows

Windows 10 or 11, 64-bit. v0.13.2, 1 November 2026.

What's new in the desktop layout

  • Every track in view: all six fit on a 1366 × 768 laptop screen
  • Tools open in the right-hand panel, so the picture is never covered
  • Keep playing and scrubbing while a tool is open
  • Drag the top of the timeline to give it more or less room
  • Trim clip edges with the mouse and drag along the ruler to scrub
  • Ctrl and the mouse wheel zoom the timeline around the pointer
  • Drop files from File Explorer anywhere on the window to import them

Install

  1. Download Ordo-Windows-Setup.exe and run it.
  2. The installer is not code-signed yet, so Windows SmartScreen may warn you. Choose More info, then Run anyway.
  3. Pick an install folder, then open Ordo from the Start menu.
